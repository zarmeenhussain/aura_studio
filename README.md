## 🎯 About

**AURA STUDIO** is a luxury beauty & cosmetics e-commerce UI featuring a curated product catalog, lookbook, and elegant shopping experience — crafted with precision for modern beauty enthusiasts.

---

## 🌟 Pages

| Page | Description |
|------|-------------|
| `index.html` | Hero landing, featured products & brand story |
| `shop.html` | Full product catalog with filters |
| `product-detail.html` | Individual product detail view |
| `lookbook.html` | Editorial lookbook & style inspiration |
| `about.html` | Brand philosophy & values |
| `contact.html` | Customer support & inquiry form |

---

## 🛠️ Technology Stack

- **Markup**: Semantic HTML5
- **Styling**: CSS3 with custom properties & animations
- **Scripting**: Vanilla JavaScript ES6+
- **Assets**: High-resolution optimized imagery
